# SmartEdu-DoFee 学习进度监控器

> 当前版本：**v1.17.0** ｜ 开源协议：[GNU General Public License v3.0 (GPL-3.0)](./LICENSE)

**SmartEdu-DoFee 学习进度监控器** 是一款配合**国家中小学智慧教育平台**（`basic.smartedu.cn`）与 **DoFee 学习系统** 使用的浏览器插件。安装后，它会在后台默默帮你统计真实有效的看课时长、同步教材目录与学习记录，还可以一键开启错题与习题整理，让你和家长随时掌握学习进度。

---

## 一、 核心功能介绍

打开浏览器右上角的插件图标，所有功能都在一个简洁的小弹窗里完成，不会遮挡网页上的视频画面：

### 1. 真实学习进度与时长统计
- **自动识别课程**：进入智慧教育平台看课时，自动识别当前课程名称、学段、年级和学科信息。
- **真实时长防误算**：按实际观看秒数精确累计「真实有效学习」时长。快进拖拽或反复拖动同一段进度条不会被重复计入，确保学习记录真实可靠。
- **断网也不丢记录**：遇到网络波动时，学习进度会先安全保存在本地队列中，等网络恢复后自动上传；你也可以在面板中点击**「冲刷」**按钮手动立即同步。

### 2. 教材目录自动同步
- 开始观看某一门教材的视频课程时，插件会自动整理该教材的完整章节与课时目录并同步到 DoFee 系统，方便查看整本书还剩哪些课没学。

### 3. 历史学习记录衔接同步
- 自动将你在智慧教育平台上已有的学习进度同步到 DoFee 账号中，面板的**「学习记录同步」**栏会显示当前同步状态，新学与已学进度无缝衔接。

### 4. 错题本与我的习题同步（按需开启）
- 在面板的**「错题本与我的习题同步 (可选)」**区域，你可以按需要勾选开启：
  - **同步错题本**：自动同步你在智慧教育平台产生的错题，整理好题干、题型、难度（`易` / `较易` / `中` / `较难` / `难`）与标准答案解析，方便日后针对性复习。
  - **同步我的习题**：同步你练过的习题记录，错题与普通练习自动分开管理，互不混杂。

### 5. 多账号绑定与自动切换（最多支持 3 组）
- **适合多孩家庭或共用电脑**：最多可在插件中绑定 **3 组**「智慧教育平台账号 ↔ DoFee 学员账号」的一对一关系。
- **切换账号自动跟随**：在智慧教育平台切换登录不同的学生账号时，插件会自动识别并切换到对应的 DoFee 账号，无需每次在插件里重新输入密码。
- **防串号安全提醒**：如果检测到当前网页登录的学生与上次写入记录的账号不一致，插件会主动弹窗确认，防止把一个人的学习记录误存到另一个人名下。

### 6. 顶栏状态与一键更新生效
- 插件弹窗最顶部会清晰展示当前版本号、智慧平台连接状态以及当前激活的 DoFee 账号。
- 当插件有新版本准备就绪时，顶栏会亮起提示并出现**「🔄 重载生效」**按钮，点击即可立即启用新版。

### 7. 学习记录本地导出（CSV）
- 在控制面板的**「DOFFEE网站域名 / API 地址」**区域，支持填写本地文件夹路径或点击**「📁 选择目录」**授权本地目录，将当前智慧平台账号的学习记录导出为按智慧平台账号命名的 `.csv` 文件（带 UTF-8 BOM，Excel 可直接打开）。
- 导出内容仅包含学员的**教材名称**、**教材目录（章 / 节 / 课时名称）**、**目录对应视频课观看进度**以及**最后观看时间**，不会导出错题本与习题本。

## 二、 新手快速上手指南

只需 4 步，几分钟即可开始使用：

### 第 1 步：安装插件到浏览器
1. 从发布页或管理员处获取已打包好的插件文件夹（若使用源码包，构建后的插件目录位于 `.output/chrome-mv3`）。
2. 在 **Chrome** 或 **Edge** 浏览器地址栏输入 `chrome://extensions`（Edge 浏览器可输入 `edge://extensions`）并回车，进入扩展程序管理页。
3. 打开页面右上角的**「开发者模式」**开关。
4. 点击左上角**「加载已解压的扩展程序」**，选择插件所在文件夹即可完成安装。建议把插件固定在浏览器右上角工具栏，方便随时查看。

### 第 2 步：填写你的 DoFee 系统地址
1. 点击浏览器右上角的 **SmartEdu-DoFee** 插件图标，打开控制面板。
2. 找到**「DOFFEE网站域名 / API 地址」**输入框，填入你的 DoFee 服务网址（例如 `https://your-domain.example`）。
3. 点击**「保存域名」**，若浏览器弹出访问权限确认窗口，请点击**「允许」**。

### 第 3 步：绑定学生账号
1. 在浏览器中打开 [国家中小学智慧教育平台](https://basic.smartedu.cn) 并登录学生账号。
2. 再次点击右上角的插件图标，在**「多用户绑定与自动激活」**的空闲槽位中，输入对应的 `dofee2` 学员用户名和密码。
3. 点击**「🔐 验证登录并建立一对一绑定」**，提示绑定成功后即可开始同步。

### 第 4 步：正常看课，自动同步
- 接下来像平时一样在智慧教育平台看课、做题即可，插件会自动完成记录与同步。
- 如需同步错题或习题，只需在面板中勾选**「同步错题本」**或**「同步我的习题」**。
- 如果暂时不想同步，可以点击**「退出当前激活」**临时挂起（已绑定的槽位关系会保留，不会丢失）；如需更换账号，可在对应槽位点击**「解绑该槽位」**并输入密码确认解除。

## 三、 常见问题解答

- **Q：为什么拖动视频进度条快进后，「真实有效学习」时间没有增加？**  
  A：这是插件的防虚增设计，只有真实播放观看的时间才会被记录下来，重复播放同一段也不会重复计算。
- **Q：两个孩子共用同一台电脑登录不同账号，学习记录会混在一起吗？**  
  A：不会。你可以在插件里为每个孩子分别绑定一个独立槽位；切换智慧教育平台账号时，插件会自动切换到对应的 DoFee 账号，并在可能发生混淆时弹窗提醒确认。
- **Q：只打开控制面板，为什么显示“需打开智慧平台页”？**  
  A：课程状态、平台当前登录学生信息和实时同步操作需要读取你当前正在浏览的智慧教育平台网页。请先打开并切换到智慧教育平台标签页，再点击插件图标即可正常显示。
